## 0. 结论（先看这三条）

1. **在横截构型上，三方（SISL / OCCT / 认证覆盖）结果一致**——这比"别人都算不出来"更难写但更可信。
2. **在退化/相切构型上分化**：OCCT 公开 API 直接漏（C 角点、D 整条对角线）；SISL 能给出几何对象，但**没有证书**，且拓扑输出随容差剧烈变化（D 在 epsge=1e-4 时 70 条曲线，1e-6 时 **1628 条**微曲线 + 346 点，2.9 s）。
3. **本文的可辩护差异不是"算得出"，而是"证书 + 无遗漏"**：认证侧对 D 给 85,344 个覆盖盒（145 ms），是**可证超集**；SISL 的曲线残差虽然在容差内（max|f1−f2|≈1e-14），但输出拓扑不可用、无存在唯一性证明。→ 论文 §7.8 与 Table 10 必须按这个口径重写。

## 3. 矩阵表示法最小复现（Busé–Mourrain 路线的最新代表 = Jia–Li–Cheng CAD 2022）

- 已实现"curve × 双三次 graph 曲面"的伴随矩阵特征值版本，明确标注 **minimal reproduction, not a full implementation of Jia 2022 / TB–M 2009**（完整 moving-surface / Dixon 消元未实现，算法要点与原因写在 `matrix_baseline.md §2`）。
- 结果：横截 1 根、多根 3 根均正确（残差 ~1e-17，0.05–0.23 ms）；**二重根返回 2 个重特征值需去重**；有理曲线清分母引入 12 个特征值里仅 1 个真根。
- 2×2/3×3 graph-patch：A/B/C/E 正确；**D 每 t 给 2 个重特征值 → 点数翻倍（402 vs 201）**。
- 同题认证对照：横截/多根 1/3/1 根簇（0.7–10.6 ms）；二重根 **185,364 覆盖盒 / 7 s**。
- **可写进论文的结论**："代数法快、但需要重数分析；区间认证慢、但给可证覆盖"——这是一个诚实的 trade-off，而不是"我们更快"。
