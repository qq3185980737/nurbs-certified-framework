==== 补充1：曲面-曲面求交（SSI）保证性处理 — 图曲面求交曲线盒带覆盖 ====

[A] f1=s^2+t^2, f2=2t^2 → f=s^2−t^2，求交曲线 s=±t（对角线）
    排除盒=4052  覆盖盒=3070  细分=7121 → 盒带覆盖对角线
    验证 f(对角线)=0：f(0.5,0.5)=0.00e+00  f(0.8,0.8)=0.00e+00
    ✓ 区间排除严格（区间不含0→无解）⇒ 未排除盒并集 ⊇ 求交曲线，无遗漏

[B] f1=s^2+t^2, f2=s^2+t^2+0.3 → f=0.3 恒正（两图不相交）
    排除盒=1  覆盖盒=0  → 全域被排除，正确拒绝（无求交）

[C] f1=s+0.5t, f2=0 → 求交直线 s+0.5t=0（仅角点(0,0)在域内）
    排除盒=20  覆盖盒=1  细分=20 → 仅覆盖角点附近，正确

[D] f=(s-t)^2 退化切触，真交线=整条对角线 s=t（OCCT IntSS 返回 0 线）
    排除盒=40188  覆盖盒=85344  细分=125531 → 盒带覆盖对角线 s=t
    验证 f(s,t)=0 at s=t：f(0.5,0.5)=0.00e+00  f(0.8,0.8)=0.00e+00
    ✓ 覆盖盒带 ⊇ 对角线 s=t：本框架保留退化切触交线，而 OCCT 返回 0 线（漏解）

结论：SSI 保证性处理落地——图曲面求交曲线 f1−f2=0 用区间排除+细分得到覆盖盒带，
      排除严格 ⇒ 覆盖盒带 ⊇ 求交曲线（无遗漏机器证明），填补统一框架的 SSI 缺口。
