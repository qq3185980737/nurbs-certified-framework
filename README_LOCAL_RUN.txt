================================================================================
NURBS 统一数值框架几何计算系统 - 本地运行指南
================================================================================

【快速启动】
1. 直接双击 index.html 文件，使用 Chrome、Firefox 或 Edge 浏览器打开
2. 无需安装任何依赖，无需启动服务器，零配置运行

【支持的浏览器】
✅ Google Chrome (推荐)
✅ Mozilla Firefox
✅ Microsoft Edge
⚠️ Safari (部分功能可能受限)

【常见问题解决】

问题 1: 页面显示空白或样式丢失
解决方案:
- 检查网络连接（TailwindCSS 使用 CDN 加载）
- 尝试刷新页面 (F5 或 Ctrl+R)
- 清除浏览器缓存后重试

问题 2: 点击"导出数据"无反应
解决方案:
- 检查浏览器是否阻止了弹出窗口
- 在浏览器地址栏右侧查找"已阻止弹出窗口"图标并允许
- 尝试使用 Chrome 或 Firefox 浏览器

问题 3: 控制台显示模块加载错误
解决方案:
- 确保所有 src/ 目录下的文件完整存在
- 不要移动 index.html 文件位置，保持与 src/ 目录的相对路径
- 使用现代浏览器（ES6 模块支持）

问题 4: Canvas 不显示或交互无响应
解决方案:
- 检查浏览器是否支持 HTML5 Canvas
- 尝试调整浏览器窗口大小触发重绘
- 按 F12 打开开发者工具查看错误信息

【文件结构说明】
index.html          - 主页面文件（入口）
src/
  ├── diagnostics.js        - 错误诊断模块
  ├── nurbs/
  │   └── math_core.js      - NURBS 数学核心库
  ├── render/
  │   └── canvas_engine.js  - Canvas 渲染引擎
  └── solver/
      └── unified_solver.js - 统一求解器

【功能特性】
- 两条 NURBS 曲线的交互式编辑
- 自动判别：相交/相切/分离状态
- 高精度数值迭代求解（Newton-Raphson + LM 阻尼）
- 包围盒预筛选加速
- 控制点拖拽编辑（开发中）
- 计算结果导出为 JSON

【技术说明】
- 纯前端实现，无需后端服务
- 使用 ES6 模块系统
- TailwindCSS (CDN) 样式框架
- 原生 Canvas 2D 渲染
- 支持 file:// 协议本地运行

【注意事项】
1. 首次加载可能需要几秒钟下载 CDN 资源
2. 复杂曲线计算可能需要较长时间（取决于迭代次数）
3. 建议保存重要配置数据到本地（使用导出功能）
