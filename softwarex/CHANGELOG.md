# Changelog

## 0.1.0 — 2026-11-25

- Initial SoftwareX-oriented packaging.
- `ssi-cert` CLI: `verify`, `verify-dir`, `info`.
- Accept/reject exit codes.
- Example certificates from the AEA artifact.
- pytest suite for accept, reject, malformed input, directory verification, and chunked certificates.
- Python reference verifier (stdlib only).
- Optional C++/GMP verifier source.
